# Startupilot 线索短片

接到改片要求时，先打开最近一次获认可的工程、分句录音和成片。用户只改语速时，沿用镜头、音色和动作落点，把新配音排回原时间线。用户只要策划或提示词时，交付相应文本即可。首次制作成片时走以下流程。

## 先写片尾要回答的那个问题

用一句口语写出“观众看到了什么，想知道什么”。找到一个能在开头和片尾各出现一次的具体物件或动作，写出两次观看的意义有什么不同。对纪实题材，为决定结论的日期、画面和因果记录可核查出处；档案原件、示意重演和创作性推断在片中清楚标识。

找出两至四条真正影响结果的线索。给每条各写一行「障碍 → 可见证据或行动 → 改变了什么 → 片尾哪一刻能看见它的作用」。删除一条后，结论若完全不受影响，重新组织它。题材只有两条线时就讲两条。地点决定结果时用地图，部件协同用剖面图，身份或证据关联用档案墙，时间差决定结果用并列时钟。让每一处特写都能在同一张总图上找到。

## 为观众安排视线

在代码中固定世界坐标，先构好总览，再定特写。默认 60 秒横版可按此起稿，用户指定的片长、比例和节奏优先。

| 时间 | 需要观众看懂的变化 | 可选动作 |
|---|---|---|
| 0–6 秒 | 从一个细节发现疑问 | 定住足够久让人看见，然后拉远 |
| 6–12 秒 | 总图上看清线索与结果的位置 | 从物件过渡到全景，短暂停留 |
| 12–35 秒 | 逐条看到问题、证据和后果 | 沿真实路径追随，向下探入结构，或同机位对照前后 |
| 35–41 秒 | 数条线第一次同时解释一个动作 | 回到已见过的总图，逐条亮起，再移向汇合点 |
| 41–54 秒 | 观众亲眼验证结果 | 给关键动作完整的起点、变化和终点；需要时锁定机位 |
| 54–60 秒 | 开头那个细节有了新的含义 | 回到相同构图，用结果或人物的后续行动收束 |

给每段写「从哪里看 → 移到哪里 → 为什么此时移动」。如果相邻三段都向同一方向横移，试用总览回撤、纵深推近、改变高度，或让主体动而相机停。弧线适合绕过前景、显露空间关系。看日期、脸或字幕时稳住视线。对需要同空间运镜的段落，使用 scripts/camera_path.py 生成逐帧机位，见 references/production.md。

## 用实际录音锁定剪辑

先做能连贯讲出故事的口播稿，再拆成短句。默认普通话每秒约 7 个实际念出的汉字，可用 6.7–7.3 作整段容差。在 60 秒里先留约 8–12 秒给呼吸、读图与动作声，其余时间约容纳 336–364 字。用户可改目标语速。专名、年代、单位先写成实际读法，另存适合观看的字幕。写出能引导视线的短句，如“看这枚销钉”，删掉“时代的浪潮滚滚向前”一类抽象过场。

逐句生成或录制配音，保存裁去首尾空白的 PCM WAV，保留句内节奏。先试听专名、数字和情绪。用各句实际音频长度安排字幕、间隙和画面。遇到冲突，优先缩句、重录、移动前一处停顿；人物对白还需对应说话者和轮次。遇到已有配音近于目标时，允许小幅保调变速。

挑出所有决定理解的“词落下、事情发生”时刻。在录音中听取该词起点或取得对齐时间戳；记录该帧应亮起的物证、变化的数字或起落的主体。只有与同一动作为因果关系的拟音才跟随关键词；氛围声独立铺设。默认关键词与指定事件相差不超过两帧。字幕另按整句可读时间排版。用 scripts/cue_sheet.py 检查语速、重叠和记录的锚点，再以成片抽听复核。

## 把工程渲染成片

检查本机中文语音、可显示中文字的字体、逐帧绘图环境、FFmpeg 和 ffprobe。选择当前可用实现。优先复用用户工程；新工程可用 Pillow 画 PNG 帧，经原始帧管道送入 FFmpeg，或用现有 Canvas/视频渲染器。保留世界坐标和镜头函数，按相同时间轴触发主体动作、音效和烧录字幕。对白居中，动机明确的近景声分层，降低人声下面的伴奏与风声。保存原始素材的来源、作者、授权和所作处理。

先在草稿分辨率检查开场、每条线索、汇合、事件前后及结尾；检查站点是否可辨、主体和字幕有无重叠、是否有连着几秒的无意义移动。再听无画面音轨，确认每句易懂、效果声有空间，最后看带声音的关键段。以 ffprobe 核对成片时长、帧率、音视频轨，查看导出画面确认中文字幕已烧录，留可编辑 SRT。用户要成片时交付可播放 MP4 和可复现工程，指出实际缺失或未验证的项。
